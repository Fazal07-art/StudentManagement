# Student Management System

## Description

A Java-based Student Management System developed as a Computer Science project.

## Features

- Enter student name
- Enter student age
- Enter student marks
- Display student details
- Calculate student grade

## Technologies Used

- Java
- Object-Oriented Programming
- Git
- GitHub

## Grade System

| Marks | Grade |
|------|------|
| 90 and above | A |
| 75 - 89 | B |
| 60 - 74 | C |
| 50 - 59 | D |
| Below 50 | F |

## How to Run

1. Clone the repository.
2. Open the project in VS Code or another Java IDE.
3. Compile the Java program.
4. Run the program.
5. Enter the student details when prompted.
